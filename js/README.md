## 📖 Overview

TechVerse India is a modern, responsive web application built to help students, freshers, and software professionals discover leading IT companies across India.

The platform provides detailed information about companies, hiring categories, technology stacks, fresher opportunities, salary ranges, locations, and career resources — all in one place.

Designed with a premium SaaS-inspired interface, TechVerse delivers a smooth and engaging browsing experience using only HTML, CSS, and Vanilla JavaScript.
